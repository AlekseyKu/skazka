# 📚 Портал в Сказку - Telegram Bot

Telegram-бот для генерации и озвучки персонализированных сказок с использованием AI и синтеза речи.

## 🎯 Описание

"Портал в Сказку" — это интеллектуальный Telegram-бот, который создаёт волшебные сказки в духе русского фольклора. Бот генерирует уникальные истории с помощью OpenAI GPT и озвучивает их голосами персонажей (Кот Баюн и Русалка) через Yandex SpeechKit.

### Основные возможности

- 📖 **Генерация сказок по теме** — создание персональных сказок на заданную тему
- 🧸 **Именные сказки** — сказки с главным героем, имя которого указал пользователь
- 📚 **Случайные сказки** — получение случайной сказки из базы данных
- 🛌 **Сказки на ночь** — успокаивающие сказки с колыбельными для детей
- 🎙 **Озвучка** — генерация аудиоверсий сказок через Yandex TTS
- 💫 **Система подписок** — различные тарифные планы с разными возможностями
- 🪙 **Система монет** — альтернативная валюта для получения сказок
- 🎁 **Коллекция** — сохранение истории созданных сказок (для расширенных тарифов)

## 🐳 Запуск через Docker (dev)

> Актуально для текущей разработки (API + Mini App + Postgres + Bot).

### 1) Подготовьте `.env`

- Скопируйте `.env.example` в `.env`
- Заполните ключи: `BOT_TOKEN`, `ADMIN_ID`, `OPENAI_API_KEY`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`

### 2) Запуск контейнеров

```bash
docker compose -f docker-compose.dev.yml up -d --build
```

### 3) Проверки

- API: `http://localhost:8000/health`
- Mini App: `http://localhost:5173`
- Логи бота:
```bash
docker compose -f docker-compose.dev.yml logs --tail=50 bot
```

### 4) Остановка

```bash
docker compose -f docker-compose.dev.yml down
```

## 🚀 Установка и настройка

### Требования

- Python 3.8+
- Telegram Bot Token
- OpenAI API Key
- Yandex Cloud API Key и Folder ID

### Шаги установки

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/AlekseyKu/skazka.git
cd skazka
```

2. **Создайте и активируйте виртуальное окружение:**

   **Windows (PowerShell):**
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

   **Windows (CMD):**
   ```cmd
   python -m venv venv
   venv\Scripts\activate.bat
   ```

   **Linux/Mac:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Создайте файл `.env` в корне проекта:**
```env
BOT_TOKEN=your_telegram_bot_token
AI_TOKEN=your_xai_token  # Не используется в текущей версии
YANDEX_API_KEY=your_yandex_api_key
YANDEX_FOLDER_ID=your_yandex_folder_id
OPENAI_API_KEY=your_openai_api_key
ADMIN_ID=your_telegram_user_id
```

5. **Запустите бота:**
```bash
python main.py
```

> **Примечание:** Убедитесь, что виртуальное окружение активировано перед запуском бота. После деактивации окружения (команда `deactivate`) бот не будет работать, пока вы снова не активируете venv.

## 📋 Структура базы данных

Проект использует SQLite базу данных (`skazka.db`) со следующими таблицами:

### Таблица `users`
Хранит информацию о пользователях:
- `user_id` (INTEGER PRIMARY KEY) — ID пользователя Telegram
- `subscription` (TEXT) — тип подписки: `free`, `gold`, `extended`, `premium`
- `subscription_end` (TEXT) — дата окончания подписки (ISO формат)
- `coins` (INTEGER) — количество монет
- `daily_limit` (INTEGER) — дневной лимит текстовых сказок
- `audio_limit` (INTEGER) — дневной лимит аудиосказок

### Таблица `tales`
История сказок пользователей:
- `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
- `user_id` (INTEGER) — ID пользователя
- `text` (TEXT) — текст сказки
- `audio_path` (TEXT) — путь к аудиофайлу
- `type` (TEXT) — тип сказки: `text`, `audio`, `named`, `named_audio`, `night`, `night_audio`
- `date` (TEXT) — дата создания (ISO формат)

### Таблица `skazki`
Общая база всех сгенерированных сказок:
- `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
- `text` (TEXT) — текст сказки
- `audio_path` (TEXT) — путь к аудиофайлу
- `type` (TEXT) — тип сказки

### Таблица `stats`
Статистика использования:
- `user_id` (INTEGER PRIMARY KEY)
- `tts_minutes` (REAL) — использовано минут TTS
- `tales_count` (INTEGER) — количество созданных сказок

## 🎮 Команды и функции бота

### Главное меню

- **📖 Расскажи сказку** — генерация сказки по заданной теме (требуется подписка)
- **📚 Расскажи рандомную сказку** — получение случайной сказки из базы
- **🧸 Расскажи именную сказку** — создание сказки с именем главного героя (2 монеты или Premium)
- **🛌 Сказка на ночь** — успокаивающая сказка перед сном (Extended/Premium)
- **🗣 Выбрать голос** — выбор голоса для озвучки (в разработке)
- **💫 Подписка** — информация о тарифных планах
- **🪙 Монеты** — проверка баланса и покупка монет
- **🎁 Моя коллекция** — просмотр сохранённых сказок (Extended/Premium)
- **ℹ Помощь** — справка по использованию бота

### Команды

- `/start` — запуск бота и регистрация пользователя

## 💎 Тарифные планы

| Тариф | Цена | Возможности |
|-------|------|-------------|
| **Бесплатный** | 0 ₽ | 1 текст/день, 3 дня аудио |
| **Золотой** | 499 ₽ | 1 аудио/день + текст |
| **Расширенный** | 999 ₽ | 2 аудио/день, доступ к коллекции |
| **Премиум** | 2990 ₽ | Безлимит, именные сказки, все функции |

### Система монет

Монеты используются как альтернатива подписке для получения платных функций:
- 📖 Сказка по теме — 1 монета
- 🎧 Аудиосказка — 1 монета
- 🧸 Именная сказка — 2 монеты
- 🌙 Сказка с колыбельной — 2 монеты

**Пакеты монет:**
- 5 монет — 149 ₽
- 15 монет — 399 ₽
- 50 монет — 999 ₽

*Примечание: система платежей находится в разработке.*

## 🔧 Технологии

### Основные библиотеки

- **aiogram 3.10.0** — асинхронный фреймворк для Telegram Bot API

- **OpenAI GPT-3.5-turbo** — генерация текста сказок

## 📝 Генерация сказок

### Системный промпт

Бот использует специальный системный промпт для создания сказок в духе русского фольклора:
- Архаичный, но понятный язык
- Элементы природы и магии
- Традиционные персонажи
- Добрые уроки и яркие образы

### Параметры генерации

- **Модель:** GPT-3.5-turbo
- **Max tokens:** 2000
- **Temperature:** 0.85 (для творческого разнообразия)
